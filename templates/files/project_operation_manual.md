# hyxClaw 项目操作手册

## 功能

- 多会话对话：创建、切换、重命名、删除、截断与 LLM 摘要压缩
- 流式响应：流式输出正文、思考过程和工具调用
- 多模型配置：目前支持智谱、阿里百炼和 DeepSeek；模型可分别声明视觉能力及原生思考参数
- 文件与图片：在允许的数据目录中读取、写入、编辑、搜索、移动和删除文件；`read` 工具同时支持文本与图片（视觉模型可读取允许目录中的图片），对话框支持粘贴图片附件
- Web 搜索：可选启用 Tavily 搜索和网页抓取
- 知识库与文档：浏览、编辑 Markdown 文档，维护知识库索引；可选只读接入 Trilium 笔记
- 用量统计：按提供商、模型和日期记录 Token 使用量和费用，以及总量
- 本地存储：会话、配置、提示词和统计数据均保存在本地数据目录

## 操作说明

### 面板介绍

- **左侧栏**：管理会话，可新建、切换、重命名和删除会话。
- **中间信息流**：显示当前会话的对话、思考过程和工具调用状态；底部可选择模型与思考强度、设置写入权限并发送消息。
- 右侧栏：在 `knowledge_base/`、`inputs/` 与（若已启用）`trilium` 之间浏览文档。本地文本可预览和编辑；Trilium 笔记只读预览。打开的文件以标签页形式保留，可将当前标签的文件或选中文字作为下一条消息的上下文。

### 聊天/阅读模式

中间信息流顶部可切换聊天模式和阅读模式，选择会保存在当前浏览器中。

- **聊天模式**：中间区域显示完整对话，右侧栏显示文件树和文档预览。
- **阅读模式**：中间顶部的会话状态栏保持不动，文档预览移至中间区域；右侧栏保留文件树和文档工具栏，并在下方显示对话与输入框。

### 一般流程

1. 外部文件或图片放入${HYXCLAW_DATA_DIR}/inputs/中，或提供网址供AI读取；日常已记在 Trilium 里的内容可让 AI 搜索阅读（需启用 tools.trilium，只读）
2. 与AI聊天总结该文档主要内容
3. 要求AI在某个现有知识库建立新文件；或要求AI建立新的知识库，并写入该新文件（写入本地 knowledge_base/，不会改 Trilium）

### 系统 Prompt

系统提示词文件位于 `files/prompts/agent_system_prompt.txt`，初始化时从模板复制。每次对话启动时程序会读取该文件并在末尾自动追加 `今天的日期是YYYY/MM/DD` 行。编辑该文件即可定制 AI 的行为规则、工具使用策略和回答风格，修改后下次发送消息时生效，无需重启服务。压缩对话用的 prompt 同理，位于 `files/prompts/compaction_prompt.txt`。

### 左侧栏

#### 新建和重命名会话

点击新建按钮即可新建默认命名的会话，双击侧栏中的会话标题即可重命名。

#### 设置

左下角 ⚙ 设置面板提供以下自定义：

- **主题**：卡其、明亮（纯白）、墨灰（深色）
- **字体**：系统默认、楷体、宋体，仅影响消息正文的 Markdown 渲染区域
- **字号**：10-20px 滑块，实时预览
- **显示生成过程**：默认使用精简模式，仅显示最新过程状态与最终回复；开启后显示完整思考和工具调用过程，并在刷新后保持开启。

主题、字体和字号设置保存在浏览器 localStorage 中。显示生成过程关闭或未设置时使用默认的精简模式。

#### 面板宽度与收起

左侧会话列表宽度固定，不能拖拽调整，可通过顶部收起按钮完全收起。

#### 连接状态

左下角状态栏显示 WebSocket 连接状态：绿点表示已连接，灰点表示未连接。断线时自动尝试重连。

### 中间信息流

#### 引用文件 @

在输入框中输入 `@` 会弹出文件搜索面板，同时搜索本地 `allowedDirs` 中的文件，以及（若已启用）Trilium 笔记。Trilium 结果带 `[trilium]` 标记，插入的引用为 `trilium:{noteId}`。输入 `@` 时，当前打开的标签页默认显示在列表前方；继续输入关键词后，匹配的已打开标签仍优先于其他搜索结果。用 ↑↓ 键或鼠标选择，回车或点击确认后插入 `[路径]` 格式的引用。

#### 常用命令 /

输入 `/` 弹出命令面板，从 `files/commands.md` 中匹配预设的 Slash 命令模板。选中后命令的 prompt 文本会替换掉 `/` 触发符，可直接编辑或发送。可根据需要添加常用命令。

#### 发送图片

1. 在输入框中直接粘贴剪贴板中的图片（Ctrl+V），支持多张。图片会作为附件随消息发送，视觉模型可读取其中的内容。每张图片可单独移除。
2. 在文档预览区域打开该图片，要求模型读取。
3. 在输入框@该文件，要求模型读取。

#### 工具权限控制

输入框底部最左边"写入权限"开关：打开后 write / edit / delete / move / web_search / web_fetch 六类操作全部跳过确认弹窗，直接执行。关闭时这六类操作每次都会弹出确认框，展示操作路径和内容预览，需手动批准。切换开关只影响之后发起的权限请求，当前已显示的确认框仍需手动选择。read / list / grep 等只读工具始终直接执行，不受此开关影响。

#### compact 压缩对话

输入框底部左边第二按钮Compact按钮：长对话可通过该按钮触发 LLM 摘要压缩。弹出窗口可选择保留最近 0-3 轮对话，确认后原对话归档到 `conversation_archive/`，当前会话替换为摘要版本。适合在上下文较长时缩减 token 用量。Compact 按钮右侧显示当前会话最后一次 LLM 请求的总上下文长度，按 `inputTokens + billingOutputTokens` 计算，包含思考 Token。该数值仅在当前浏览器页面的会话缓存中保留，切换会话时显示各自的最近值，刷新页面后清空。

#### 取消模型生成

模型生成过程中，发送按钮会变为 ⏹ 停止按钮。点击后立即中断当前请求，已输出的内容保留在对话中并标注"(已取消)"。

#### 从对话流的中间重新开始

每条用户消息右侧有 ↺ 按钮。点击后确认截断，该消息之后的所有回复被删除，原文回填到输入框供你修改后重新发送。

#### Token 计数、会话用量与费用统计

点击工具栏的 📊 按钮可打开完整用量与费用统计面板：
- **每日**：7 天或 30 天的堆叠柱状图，按模型和 Provider 分色展示每日 Token 用量；可切换到费用视图查看每日费用
- **总量**：按模型 + Provider 汇总总缓存输入、总未缓存输入（两者相加为总输入）、总输出和总费用

费用按模型配置中的 `cost` 单价计算；未配置单价的模型费用记为 0。`cost` 可选配 `schedules` 分时段价格（如工作日高峰价、夜间闲时价），按北京时间匹配第一个命中的时段，未命中时使用顶层单价；不配 `schedules` 时行为与固定单价一致。统计数据持久化在 `files/usage_daily.json` 和 `files/usage_total.json` 中。

#### 知识库浏览

顶部工具栏的 📖 按钮可打开知识库总览面板，列出所有知识库及其包含的文件。每个知识库卡片显示名称、描述和文件列表，超过 5 个文件时可点击展开查看全部。

#### Git 数据同步

顶部工具栏的同步按钮可打开数据同步面板。数据目录必须是已配置远端和上游分支的 Git 工作树；同步范围完全由数据目录中的 `.gitignore` 决定。

- **拉取更新**：工作区干净时拉取远程更新，工作区有任何未提交修改时立即停止。历史分叉、冲突、认证和网络错误均不会自动处理。
- **提交并推送**：依次自动执行 `git add -A`、检查暂存区、创建带时间戳的提交，然后执行 `git push`。没有变更时不会创建空提交；推送失败时已创建的本地提交会保留。

程序不会自动 stash、merge、rebase、force push 或覆盖文件。遇到异常请在数据目录的终端中手动处理。非回环地址监听时，同步按钮和 Git 接口都会隐藏/禁用。

### 右边栏

#### 文件树

文件树顶部可在 `knowledge_base/` 与 `inputs/` 两个根目录间切换，采用两列浏览：左侧为当前目录，点击目录在右侧列展开其内容，可逐级下钻；右侧列顶部的返回按钮可回到上一级。点击文件会在下方预览区打开一个文件标签页，支持的文本文件也可进入编辑模式。

#### 文件标签页

预览区顶部是文件标签页，打开过的文件会保留为标签，可随时切换、关闭：

- 点击文件打开的是**临时标签**（文件名为斜体），此时再点击其他文件，临时标签会被替换为新文件，不会无限堆积标签
- **双击**临时标签可将其固定为**常驻标签**（标准字体）；此后点击其他文件会新建临时标签
- 点击标签右侧 × 可关闭任意标签；关闭当前标签后，该文件不再作为下一条消息的文档引用
- 标签列表、根目录选择与列宽均保存在浏览器中，刷新页面后保留

#### 工具栏按钮

右侧文档预览区顶部工具栏提供两个按钮：

- **刷新**：重新加载文档浏览器目录（`knowledge_base/` 和 `inputs/`），适合在外部修改文件后更新列表
- **编辑**：切换文档编辑模式。开启后可直接在右侧面板编辑文本文件（如 `.md`、`.txt`），保存后立即生效；每个标签独立记录编辑状态，切换标签时正在编辑的内容会自动保存

#### 划选文字带入对话

右栏文档预览中划选文字后，发送下一条消息时会自动附带当前标签打开的文件以及该文件中选中的内容和行号信息，让模型知道你正在引用的文档片段。如果打开了文件但没有选择文字，该文件被打开的信息也会传递给模型。关闭当前标签页即可清除文件打开和选中文字信息。

#### 面板宽度与收起

文档面板可通过分隔条拖拽调整宽度，也可通过收起按钮完全收起。内部还有一条水平分隔条，可调整上方文件树和下方预览区的高度比例，文件树最低可压缩到只剩顶部根目录切换行；文件树两列之间也可拖拽调整列宽。

### 异地使用

所有的本地数据就放置在${HYXCLAW_DATA_DIR}这个数据文件夹中，整个数据文件夹可以在github备份，在不同的电脑上同步该文件夹即可使用。同时Markdown知识库可以同步至手机端随时查看，iphone推荐应用Mdown。
