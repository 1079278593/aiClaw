# 03 · 组件

组件是 Token 的最后一层。按钮和输入框的状态是闭合的（默认、悬停、按下、焦点、禁用、错误），直接写死，不用等「出现三次再抽」。那条是编程里避免过早抽象的经验，用在这里会让人不知道该何时补状态。

卡片、列表、弹窗没有这套交互状态，只规定结构和间距。

两端已经有对应物，不要另起一套名字：

| 组件 | Web | Flutter |
| --- | --- | --- |
| 按钮 | `<button>`，主操作用强调色 | `FilledButton` / `TextButton` |
| 输入 | `input` / `textarea` | `TextField` |
| 卡片 | 白底区块 | `Card` 或自绘容器 |
| 列表 | 行 + 间距 | `ListTile` |
| 弹窗 | 居中浮层 | `AlertDialog` |
| 轻提示 | 行内错误文案 | `SnackBar` |

颜色一律走 [02 的角色槽位](02-tokens.md)，不写死色号。

## 按钮

一个屏幕只有一个主按钮。

| 变体 | 何时用 | 背景 | 文字 | 圆角 |
| --- | --- | --- | --- | --- |
| 主按钮 | 这一屏唯一的提交、发送、确认 | `action-primary` | `on-action` | 8～10 |
| 次按钮 | 取消、返回、次要动作 | 透明，描边 `border-strong` | `text-primary` | 8～10 |
| 文字按钮 | 行内操作、「更多」 | 透明 | `action-primary` | 8 |

状态（三种变体共用同一套列；危险按钮另表）：

| 状态 | 主按钮 | 次按钮 | 文字按钮 |
| --- | --- | --- | --- |
| 默认 | 底 `action-primary`，字 `on-action` | 透明底，描边 `border-strong`，字 `text-primary` | 透明底，字 `action-primary` |
| 悬停 | 底 `action-primary-hover`（比主色深一档） | 底 `bg-subtle` | 底 `action-soft` |
| 按下 | 与悬停相同 | 与悬停相同 | 与悬停相同 |
| 焦点 | 不改填充，加 3px 主色 20% 的描边环 | 同左 | 同左 |
| 禁用 | 底 `bg-subtle`，字 `text-disabled`，不可点 | 描边 `border`，字 `text-disabled` | 字 `text-disabled` |
| 加载中 | 保持主按钮底色，文字换成 16px 细圈，不可再点 | 同左 | 同左 |

触屏没有悬停。Flutter 上「按下」用主色深一档即可，不必再做一档。

危险按钮（删除）单独一套，不占用主按钮名额：默认底 `danger`、字 `on-action`；悬停/按下用更深的红；禁用与上表相同。删除必须再经一次弹窗确认。

规则：

- 主按钮文案用动词（发送、保存、建立），不用「确定」包办所有事。
- Web 上主按钮的悬停色已经有 `--accent-hover`，禁用色有 `--send-btn-disabled-bg` / `--send-btn-disabled-text`。新代码沿用这两处，不要再发明 `button-bg-hover`。

## 输入框

| 状态 | 边框 | 背景 | 说明文字 |
| --- | --- | --- | --- |
| 默认 | `border-strong` | `bg-card` | 无 |
| 悬停 | `border-strong` | `bg-card` | 无。边框不必为悬停再深一档 |
| 焦点 | `action-primary` | `bg-card` | 无 |
| 错误 | `danger` | `bg-card` | 字段下方 13～14 号字，颜色 `danger` |
| 禁用 | `border` | `bg-subtle` | 无，文字用 `text-disabled` |

错误用边框和一句说明表达，背景保持 `bg-card`。整块铺 `danger-soft` 只留给横幅式错误（见 [04](04-patterns.md)），不要每个输入框都变成红底。

标签和输入框间距 8。占位文字用 `text-muted`，不要把占位文字当标签——标签始终可见。

## 卡片

- 背景 `bg-card`，页面是 `bg-page`。层次靠这两层色差，默认不加阴影。
- 内边距 16。卡片之间的间距 ≥ 16，通常 24。
- 圆角 12～16。同一屏不要混用 8 和 16 的卡片。
- 只有真正浮在内容之上的菜单、弹层才用阴影：`0 4px 16px rgba(0,0,0,0.06)`。

## 列表

- 同一组内行距 12～16，或用整行点击区域代替分割线。
- 需要强分隔时用一条 `border`（`#E5E7EB` 这一档），不要每行上下都画。
- 图标和文字间距 8。图标 20 或 24，和文字视觉中线对齐。
- 选中行用 `action-soft` 浅底，文字用 `on-action-soft`。不要整行铺主色。

## 弹窗与轻提示

| 情况 | 用什么 | 不用什么 |
| --- | --- | --- |
| 需要用户做选择（删除、重命名） | 弹窗，圆角 16～20，最多两个按钮：次按钮在左，主按钮在右 | 用主色同时放两个按钮 |
| 操作结果、失败原因 | 轻提示一行字，自动消失 | 弹窗只为说「成功了」 |
| 表单校验 | 输入框就地标红 + 一句说明 | 弹窗报「请填写内容」 |

弹窗标题说清后果（「删除这条心得？」），正文补不可恢复之类的事实，按钮写「删除」而不是「是」。
