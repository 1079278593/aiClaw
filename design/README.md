# aiClaw 视觉设计

本目录存放视觉设计规范：配色、字体、间距、组件与交互细节。目标是让 Web 端与移动端共用一套「同一开始点」的视觉语言，而不是各写各的。

规范不绑定具体实现，但每条结论都应该能在代码里找到落点：

| 端 | 落点 |
| --- | --- |
| Web（服务端内嵌前端） | `server/src/server/public/styles/tokens.css`（`html[data-theme="..."]` 下的 CSS 变量） |
| 移动端（Flutter） | `mobile/lib/ui/ai_theme.dart`（`ThemeData` / `ColorScheme`） |

## 记录约定

1. **先定值，再定名。** 新颜色/间距先给出具体数值，再说明用途，避免「深一点的红」这种描述。
2. **写清反例。** 只写「用 #F7F8FA 做背景」不够，要写「不要用 #FFFFFF 配 #000000」。
3. **一套值走到底。** 同一视觉角色全端复用同一个值；要改就在本目录改，并同步改代码落点，不要就地硬编码。
4. **优先级：一致性 > 单个元素好看。** 规范没覆盖到的地方，先用最接近的已有值，再回头补规范。
