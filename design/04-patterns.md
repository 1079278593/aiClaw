# 04 · 跨页面模式

空、加载、错误、动效。这四处最容易只做「有数据」的那一屏。原则来自 [01](01-foundations.md) 第四节第 6、7 条，这里收成可直接套的结构。

## 空状态

结构固定为三行，不要只留一句「暂无」：

1. 一个淡色图标，放在 `bg-subtle` 的圆底上（Web 已有 `.empty-state-icon`）。
2. 标题：发生了什么。例：「还没有对话」「暂无知识库」。
3. 一句下一步。例：「发送消息后即可查看 Token 统计」「在左侧选择一个文件」。

没有下一步就不要造一个假按钮。图标用线性、和界面其它图标同一套（Web 用 lucide）。

已有落点：Web 的 `.empty-state`（文档、用量、知识库），会话列表的 `.session-list-empty` 目前只有一行字，补文案时对齐上面三行。

## 加载

| 等待什么 | 用什么 |
| --- | --- |
| 整页第一次出现 | 骨架：几条浅灰块，形状接近最终内容 |
| 按钮正在提交 | 按钮内一个 16px 的细圈，按钮不可再点 |
| 列表翻页 | 列表底部一个细圈，不要换成整页「加载中…」 |

文案若必须有，写「加载中」，不要用省略号动画刷存在感。Web 启动页的 `.boot-placeholder` 属于整页加载，可以保留一句字。

不要用骨架和细圈同时占满同一块区域。

## 错误

错误要回答两件事：哪里错了、接下来可以做什么。

| 场景 | 呈现 | 文案方向 |
| --- | --- | --- |
| 单字段不合法 | 输入框 `danger` 边框 + 字段下 13～14 号字 | 「请先写下内容」 |
| 一次操作失败 | 轻提示 | 说原因，能重试就给出重试 |
| 整页加载失败 | 用空状态那三行结构，图标换成警告 | 标题写失败，副文案写重试 |

颜色用 `danger-soft` 底 + `on-danger-soft` 字，不用一大块纯红。

Flutter 侧失败目前多用 `SnackBar` 只丢 `error.message`。能在调用处写成用户能执行的句子，就不要把状态码原文扔出去。

## 动效

只动画「状态变了」这件事。

| 项目 | 值 |
| --- | --- |
| 时长 | 150～250ms |
| 曲线 | ease-out（Flutter：`Curves.easeOut`） |
| 做什么 | 展开、收起、页面切换、出现与消失 |
| 不做什么 | 弹跳、旋转装饰、循环晃动 |

加载中的细圈是唯一允许持续运动的东西。尊重系统的「减少动态效果」：Flutter 用 `MediaQuery.disableAnimationsOf(context)` 为真时，时长设为 0。
