# 01 · 基础设计知识

## 本文档的适用范围

本文的「起步配方」是 **「明亮」主题的基准**。仓库里另有两套风格化主题——「卡其」（默认，暖色纸张感）、「墨灰」（暗色）——它们**不要求**符合配方色值，只要求 token 槽位齐备（见 [02-tokens.md](02-tokens.md) 的角色槽位表）。

换句话说：规范约束的是**结构与比例**（层级数量、间距网格、主色面积、圆角统一），不是每一套主题的具体色号。

这份文档是视觉设计的起点。原则一句话：**层级靠字号、字重、颜色深浅和间距来拉，不靠颜色、线条、阴影来堆。**

## 一、颜色：先定中性色，再定一个主色

### 1. 背景不要用纯白，文字不要用纯黑

纯白 `#FFFFFF` 配纯黑 `#000000` 对比太硬，看久了刺眼。用带一点点色调的灰：

| 角色 | 冷灰 | 暖灰 | 说明 |
| --- | --- | --- | --- |
| 页面背景 | `#F7F8FA` / `#F5F6F8` | `#FAF9F7` | 承载一切的最底层 |
| 卡片 / 浮层背景 | `#FFFFFF` | `#FFFFFF` | 只有「浮起来」的东西才用纯白 |
| 主文字 | `#1F2937` / `#333333` | 同左 | 标题、关键数值 |
| 次要文字 | `#6B7280` / `#666666` | 同左 | 正文、列表内容 |
| 辅助 / 说明文字 | `#9CA3AF` / `#999999` | 同左 | 时间戳、单位、提示 |
| 分割线 | `#E5E7EB` / `#EEEEEE` | 同左 | 极浅，只在必须强分隔时出现 |

要点：

- 文字颜色有 **三级足够**（主 / 次 / 辅），再加一档「禁用」灰即可。不要出现十几个近似灰。
- 页面背景与卡片背景之间的差值就是「层级」。卡片用纯白、页面用浅灰，是成本最低的层次感。

### 2. 主色选低饱和，不要用高亮纯色

纯蓝 `#0000FF`、纯红 `#FF0000` 会显得廉价。选一个饱和度降下来、明度适中的颜色：

| 色系 | 建议值 |
| --- | --- |
| 蓝 | `#4F7CFF`、`#3B82F6`（比纯蓝柔和） |
| 绿 | `#10B981` |
| 橙 | `#F59E0B` |
| 紫 | `#8B5CF6` |

主色**只用在最需要点击或最需要强调的地方**：主按钮、选中态、关键数字、链接。

面积配比参考：

- 中性色（背景 + 文字 + 线条）约 **60%**
- 辅助灰（卡片、次级块、弱化内容）约 **30%**
- 主色 **不超过 10%**

### 3. 状态色也要降饱和

| 状态 | 色值 |
| --- | --- |
| 成功 | `#10B981` |
| 警告 | `#F59E0B` |
| 错误 | `#EF4444` |

不要用荧光绿和正红。错误提示用**浅红背景 `#FEF2F2` + 深红文字 `#B91C1C`**，比一整块大红舒服得多。同理，成功和警告也应走「浅底 + 深字」的路线，而不是纯色大字块。

### 4. 暗色模式不是简单反色

| 角色 | 暗色值 |
| --- | --- |
| 页面背景 | `#121212` ~ `#1E1E1E`，不要纯黑 |
| 卡片背景 | `#1E1E1E` ~ `#2A2A2A` |
| 文字 | `#E5E7EB`，不要纯白 |
| 主色 | 提高明度、降低饱和度，否则会刺眼 |

暗色下「更亮 = 更靠前」的关系要反过来处理：卡片靠比背景**稍亮**来浮起，而不是靠阴影。

## 二、字体：少即是多，层级靠字号和字重

### 1. 字体家族最多两种

- 中文用系统字体最安全：iOS 苹方、Android 思源黑体 / Roboto。
- 英文可以用 Inter、SF Pro、Roboto。
- 不要混用多种风格差异大的字体。中英可以各一套，但正文只能有一种感觉。

### 2. 字号层级最多 4～5 级

不要出现 13、15、17 这种碎值。一套舒服的层级：

| 层级 | 字号 | 字重 |
| --- | --- | --- |
| 大标题 | 28～32 | Semibold |
| 页面标题 | 20～24 | Semibold |
| 小标题 / 强调 | 16～18 | Medium |
| 正文 | 15～16 | Regular |
| 辅助说明 | 13～14 | Regular |
| 极小字 | 11～12 | Regular（少用） |

### 3. 字重只用两档

**Regular** 和 **Medium / Semibold**。

不要在一个页面里出现 Light、Regular、Medium、Bold、Heavy 五种字重，会乱。正文 Regular，标题和按钮 Medium 或 Semibold，足够了。

### 4. 行高是「舒服」的关键

正文行高设为字号的 **1.5～1.7 倍**：

- 16 号字配 24～26 行高
- 14 号字配 21～22 行高

标题行高可以紧一点，**1.2～1.3**。行高不够，文字就会像挤在一起——这是最常见的「不舒服」来源。

### 5. 对齐和行长

- 正文**左对齐**，不要两端对齐。
- 中文每行 **25～35 个字**比较舒服，太宽眼睛会累。
- 数字和金额用**等宽数字**（tabular figures），对齐更整齐。

## 三、间距：用留白代替分割线，用分组代替边框

### 1. 所有间距用 8 的倍数

常用值：`8 / 16 / 24 / 32 / 48`。

不要出现 10、15、18 这种随手值。8 点网格是让界面「整齐」最便宜的方法。

### 2. 页面左右边距

| 端 | 边距 |
| --- | --- |
| 手机 | 16 或 20 |
| 平板 / 桌面 | 24 或 32 |

内容不要贴边，留出呼吸感。

### 3. 亲密性原则：相关的靠近，不相关的拉开

| 关系 | 间距 |
| --- | --- |
| 图标和它的文字 | 8 |
| 表单标签和输入框 | 8 |
| 同一组内的列表项 | 12～16 |
| 不同模块之间 | 24～32 |
| 大区块之间 | 40～48 |

### 4. 卡片内边距 ≥ 卡片外间距

如果卡片内边距是 16，卡片和卡片之间的间距至少 16，通常 20～24。**内部比外部紧**，视觉上才会「成组」。反过来（外紧内松）会让卡片像被挤在一起、内容却在乱跑。

### 5. 能用留白分组，就不要画分割线

大量分割线会让界面显得碎、像表格。用**间距**和**浅背景色块**来区分模块，只在真正需要强分隔的地方用一条极浅的线（`#E5E7EB`）。

## 四、其他提升「设计感」的细节

### 1. 圆角统一

不要一个页面里 4、6、8、12、16 全都有。选一套：

| 元素 | 圆角 |
| --- | --- |
| 小元素（标签、输入框） | 8 |
| 按钮 | 8～10 |
| 卡片 | 12～16 |
| 弹窗 | 16～20 |

统一比圆角大小本身更重要。

### 2. 阴影极其克制

默认**不用阴影**，用浅背景和留白分层。需要浮层时，用大模糊、低透明度的阴影：

- `0 4px 16px rgba(0,0,0,0.06)`
- `0 8px 24px rgba(0,0,0,0.08)`

不要用黑色 0.3 透明度那种「硬阴影」。

### 3. 图标风格统一

- 线性就全线性，面性就全面性。
- 描边粗细一致（常用 1.5 或 2）。
- 圆角端点统一。
- 不要混搭不同图标库。
- 图标尺寸和相邻文字视觉高度对齐，通常 20 或 24。

### 4. 图片统一比例和圆角

- 封面图统一 16:9 或 4:3。
- 头像圆形或统一圆角，不要一张圆一张方。
- 图片上的文字加一层淡淡的渐变遮罩，保证可读。

### 5. 建立清晰的视觉层级

用户第一眼看到什么、第二眼看到什么，靠**大小、颜色深浅、字重**三样来引导。一个屏幕里只留一个「最重」的元素（主按钮或关键数字），其他都退后。

### 6. 动效短、轻、有目的

- 时长 **150～250ms**，缓动用 `ease-out`。
- 只做状态变化的过渡（展开、切换、加载），不要为了动而动。
- 少用弹跳和旋转。

### 7. 空状态、加载态、错误态也要设计

不要只画「有数据」的页面：

- **空状态**：一句友好文案 + 一个淡色插图 / 图标。
- **加载**：骨架屏或轻量 spinner。
- **错误**：给出明确下一步，而不是只显示「出错了」。

这些地方最体现完成度。

## 五、一套可以直接抄的起步配方

不想逐项调时，先用这套默认值，已经能超过大多数「没设计」的原型：

| 项目 | 值 |
| --- | --- |
| 页面背景 | `#F7F8FA` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#1F2937` |
| 次要文字 | `#6B7280` |
| 辅助文字 | `#9CA3AF` |
| 分割线 | `#E5E7EB` |
| 主色 | `#4F7CFF`（或品牌色降饱和版） |
| 成功 / 警告 / 错误 | `#10B981` / `#F59E0B` / `#EF4444` |
| 标题字号 / 字重 | 20～24 / Semibold |
| 正文字号 / 行高 | 16 / 24～26，Regular |
| 辅助字号 / 行高 | 14 / 21，Regular |
| 页面边距 | 16（手机） |
| 卡片内边距 | 16 |
| 模块间距 | 24～32 |
| 小圆角 / 大圆角 | 8 / 12～16 |
| 默认阴影 | 无；浮层用 `0 4px 16px rgba(0,0,0,0.06)` |

## 最后记住三件事

1. **一致性 > 单个元素好看。** 同样的按钮、卡片、标题，全 App 用同一套值。
2. **留白大胆给。** 觉得「有点空」的时候，通常是对的；觉得「有点挤」的时候，一定是错的。
3. **少用颜色、少用线条、少用阴影。** 层级靠字号、字重、深浅和间距来拉，界面自然就「舒服」了。
