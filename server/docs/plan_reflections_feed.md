# 心得：目录是首页

> 只改「心得」这个 tab 的首页，以及从这里点进去的编辑页。聊天、人物、文档和助手会话不动。

进入「心得」先是文件夹列表，和苹果备忘录的「文件夹」页一样。笔记要再点进某个文件夹才出现。没有消息流，也不按输入方式分类。写出来的仍是该文件夹里的一篇 Markdown。

消息流、卡片、`feed`、按输入方式筛选，都不再做。之前计划里这些决定作废。不引入 `id`。打开哪一篇以当前路径为准。

## 界面

```text
文件夹页（进来就是这一页，只有文件夹）
  点文件夹名字 → 进入笔记列表
  有子文件夹时，行右侧可展开；展开只看到子文件夹，看不到笔记
  再展开更深的子文件夹，同样只有文件夹
  这一页没有笔记，也没有底部输入框
  右上角是新建文件夹

笔记列表（进入某个文件夹之后）
  头部一段：这个文件夹里的直接子文件夹，按名称
  下面才是笔记，按编辑日期分组
  点子文件夹的名字 → 再进一层笔记列表
  点笔记 → 整页编辑，返回这一页笔记列表
  右上角「创建」→ 空白整页
  底部输入框：回车换行；右侧按钮先问标题，再写进当前文件夹
```

文件夹页不列出笔记。直接躺在 `inputs/reflections/` 根上的文件，这一页看不到；新建和快速输入在根上时写入 `inbox/`。已经进入某个文件夹时，写在那个文件夹里。空文件夹仍显示。

笔记列表的头部只放直接子文件夹，不把更深处的笔记带上来。展开是文件夹页上的动作，和头部这段是同一规则：只看到文件夹。

分组按苹果备忘录的默认「按日期分组」，依据是编辑时间，从新到旧。组与组不交叉：

| 组 | 范围 |
|---|---|
| 今天 | 本地日期的今天 |
| 昨天 | 昨天 |
| 前 7 天 | 今天之前的第 2 天到第 7 天 |
| 前 30 天 | 今天之前的第 8 天到第 30 天 |
| 年份 | 更早的，按公历年，例如 `2024` |

本地日期用东八区。同一组里仍按编辑时间从新到旧。改正文或标题后，这篇进入「今天」，并排在「今天」的最上面。创建时间只记录，不决定落在哪一组。

文件夹按名称。改文件夹名字只影响它所在的那一层文件夹顺序，不改变笔记落在哪个日期组。这一期不做拖拽调整文件夹顺序，也不做画廊、置顶、按标题排序的切换。苹果备忘录里这些是附加选项，默认不用。

整页编辑参照苹果备忘录，不用现在的表单：

- 第一行是标题，字大一些。在这一行按回车，进入正文。
- 正文从第二行起，字小一些。
- 不在这一页编辑发生时刻和情境。这两个字段仍留在文件里，保存时不许写成空。
- 「拿去问」留在这一页。目录首页没有它。

底部快速输入只出现在笔记列表。标题以弹框为准，框里的文字是正文。正文为空时，右侧按钮不可用。标题弹框不能空着确定。文件名不按标题重排；磁盘上的文件名仍只在创建时取一次。

拖进来、没有 `updatedAt` 的文件，用文件修改时间决定落在哪一组。保存时写新的 `updatedAt`，已有 `createdAt` 不改；没有 `createdAt` 时，把文件出生时间写进去，不要写成这次保存的时刻。

网页宽屏左侧是文件夹树，展开也只有子文件夹；选中一个文件夹后，右侧是它的笔记列表（头部子文件夹，下面按日期分组）。窄窗口与手机相同：先文件夹页，再笔记列表，再整页编辑。不再用「时间序 / 目录」切换。

语音若以后要做，只往当前输入位置填字（底部框或整页正文），不单独成一种笔记。这一期不做。

## 储存

一篇仍是 `inputs/reflections/` 下的一个 Markdown。不另建库，不记录语音、键盘或拖入。

拖进目录的文件和输入框创建的文件都出现在目录里。文件名只在创建时按标题取一次，方便在电脑上认出。改标题不改文件名。

客户端没展示的 `context`、`occurredAt` 用省略表示保持原值，不要传空字符串。`createdAt` 已有则保持。

## 接口

现有树和单篇接口够用，不新增「只返回消息」的列表。

| 接口 | 这一期 |
|------|--------|
| `GET /api/reflections?view=tree` | 文件夹页和笔记列表都用它。文件节点带 `updatedAt`。日期分组在客户端算 |
| `POST /api/reflections` | 快速输入和「创建」都走它。带 `title`、`body`、当前 `folder`。写入当时的 `createdAt` |
| `GET` / `PUT /api/reflections/content` | 仍按路径。省略的字段保持原值。已有 `createdAt` 不改 |
| `GET /api/reflections`（扁平时间序） | 心得首页不再调用 |

`import`、移动、按日期归夹的接口留着，这一期界面不改它们。

## 下一步

对照现在的实现，按这个顺序做。

1. **手机先做文件夹页。** `reflections_list_page.dart` 现在是时间序列表。改成只列文件夹：点名字进入笔记列表，有子文件夹才显示展开，展开不出现笔记。右上角新建文件夹。去掉时间序列表。
2. **笔记列表。** 进入文件夹后，头部是直接子文件夹，下面按「今天 / 昨天 / 前 7 天 / 前 30 天 / 年份」分组。底部多行输入框，回车换行，右侧按钮先问标题，再 `POST` 到当前文件夹。右上角「创建」进入空白整页。
3. **整页改成备忘录。** `reflection_page.dart` 去掉发生时刻、情境两个输入框。第一行标题、下面正文，正文字号小于标题。从「创建」进来是空的，写过再保存。从目录点进来是打开已有篇。保存仍用现有 `PUT`，不传空的情境和发生时刻。
4. **网页去掉时间序首页。** `reflections.js` 里「时间序 / 目录」切换和默认打开第一篇，改为文件夹树加笔记列表，分组与手机相同。编辑区改成标题一行加正文。粘贴导入、拆分文件先留在工具里。
5. **分组用编辑时间。** `store.ts` 保存时更新 `updatedAt`，不得改掉已有 `createdAt`。树或列表要带上 `updatedAt`，分组在客户端按东八区算。补测试：改正文后 `updatedAt` 变、`createdAt` 不变；子文件夹改名不改变笔记的 `updatedAt`。
6. **文档。** 改 `mobile/docs/client_surfaces.md` 和 `api_shapes.md` 第 8 节里「时间序列表」的说法。

## 不做

- 不做消息流、卡片高度、`feed`、摘录、输入方式标记。
- 不建 index，不建来源类型表，不加 `id`。
- 不在正文里嵌可播放的录音。
- 不做逐字自动保存。这一期用页面上的保存。
